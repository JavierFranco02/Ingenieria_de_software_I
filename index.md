# ChipeSoft - Sistema Web de Gestión y Ventas para Chipería

**Trabajo Práctico Integrador — Ingeniería de Software**

ChipeSoft es un sistema web de gestión comercial y control de stock que automatiza las ventas en mostrador, el registro de horneadas y la liquidación diaria de dinero de los vendedores ambulantes. Se desarrolla para la chipería "Chiperia la Caraguateña" de la ciudad de Caraguatay, con el fin de informatizar sus procesos manuales en cuadernos y garantizar un control preciso de sus ingresos.
